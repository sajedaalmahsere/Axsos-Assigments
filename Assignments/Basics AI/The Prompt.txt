## 🔹 What is the `<legend>` tag in HTML?

The `<legend>` tag is used to give a **title or description to a group of form fields**.

It is normally used **inside a `<fieldset>` element**.

Think of it like this:

> **`<fieldset>` = a box that groups related inputs**
> **`<legend>` = the title of that box**

### Simple example

```html
<form>

    <fieldset>
        <legend>Personal Information</legend>

        <label>First Name:</label>
        <input type="text">

        <br><br>

        <label>Last Name:</label>
        <input type="text">

    </fieldset>

</form>
```

It will look approximately like:

```text
┌── Personal Information ──────────────┐
│                                      │
│ First Name: [____________]           │
│                                      │
│ Last Name:  [____________]           │
│                                      │
└──────────────────────────────────────┘
```

So **Personal Information** is the `<legend>`.

---

# 🔹 Why do we use `<legend>`?

Imagine you have a big form with many inputs:

```text
Registration Form

Personal Information
    First Name
    Last Name
    Age

Contact Information
    Email
    Phone

Account Information
    Username
    Password
```

It would be useful to visually and semantically separate these groups.

That's where `<fieldset>` and `<legend>` come in.

```html
<form>

    <fieldset>
        <legend>Personal Information</legend>

        <label>First Name:</label>
        <input type="text">

        <label>Last Name:</label>
        <input type="text">

    </fieldset>


    <fieldset>
        <legend>Contact Information</legend>

        <label>Email:</label>
        <input type="email">

        <label>Phone:</label>
        <input type="tel">

    </fieldset>

</form>
```

Now we have **two groups**:

* `Personal Information`
* `Contact Information`

---

# 🔹 Where can I use `<legend>`?

The important rule is:

### `<legend>` is used as the first child of `<fieldset>`.

For example:

```html
<fieldset>

    <legend>Account Information</legend>

    <!-- form fields here -->

</fieldset>
```

Usually you'll use it with forms:

```html
<form>
    <fieldset>
        <legend>Login</legend>

        <label>Email:</label>
        <input type="email">

        <br><br>

        <label>Password:</label>
        <input type="password">

        <br><br>

        <button>Login</button>
    </fieldset>
</form>
```

---

# 🔹 `<fieldset>` vs `<legend>`

This is very important to understand.

### `<fieldset>`

Groups related form elements.

```html
<fieldset>
    ...
</fieldset>
```

### `<legend>`

Gives that group a title.

```html
<legend>Login Information</legend>
```

Together:

```html
<fieldset>

    <legend>Login Information</legend>

    <input type="email">
    <input type="password">

</fieldset>
```

Think of it like a **folder**:

```text
📁 Personal Information
   ├── First Name
   ├── Last Name
   └── Age
```

`fieldset` = 📁 folder
`legend` = folder name

---

# 🔹 Is `<legend>` the same as `<label>`?

❌ No. This is a very important difference.

### `<label>`

Describes **one input**.

```html
<label for="email">Email:</label>
<input type="email" id="email">
```

Here, `Email` describes the email input.

### `<legend>`

Describes **a group of inputs**.

```html
<fieldset>

    <legend>Contact Information</legend>

    <label>Email:</label>
    <input type="email">

    <label>Phone:</label>
    <input type="tel">

</fieldset>
```

Here:

**Contact Information** describes the whole group.

---

# 🔹 A very common use: Radio buttons

This is one of the best examples for understanding `<legend>`.

Suppose you ask:

**What is your gender?**

You have multiple radio buttons that belong to the same question.

```html
<fieldset>

    <legend>Gender</legend>

    <input type="radio" id="male" name="gender">
    <label for="male">Male</label>

    <br>

    <input type="radio" id="female" name="gender">
    <label for="female">Female</label>

</fieldset>
```

Here:

```text
┌── Gender ────────────────┐
│                          │
│ ○ Male                   │
│                          │
│ ○ Female                 │
│                          │
└──────────────────────────┘
```

`legend` tells the user:

> "These radio buttons are asking about Gender."

---

## 🧠 Remember this

If you see:

```html
<fieldset>
    <legend>Something</legend>

    <!-- related inputs -->

</fieldset>
```

Think:

> **fieldset = Group**
> **legend = Name of the Group**

And:

> **label = Name of an individual input**

### Quick comparison

| Tag          | Purpose                        |
| ------------ | ------------------------------ |
| `<form>`     | Contains the form              |
| `<fieldset>` | Groups related form fields     |
| `<legend>`   | Gives the group a title        |
| `<label>`    | Describes one input            |
| `<input>`    | Gets information from the user |

As a beginner, the main thing to remember is: **you don't normally use `<legend>` by itself. It belongs inside `<fieldset>` and gives that group of form controls a meaningful title.**
