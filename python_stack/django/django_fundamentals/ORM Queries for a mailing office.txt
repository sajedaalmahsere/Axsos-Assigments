## 1. Users whose birthday is today

Use `filter()` with Django's `birthday__month` and `birthday__day` lookups.

Python

```
from datetime import date

today = date.today()

users = User.objects.filter(
    birthday__month=today.month,
    birthday__day=today.day
)
```

How it works:

* `birthday__month` matches the current month.

* `birthday__day` matches today's day.

* Both conditions must match.

## 2. Users who have no mail items

Use `filter()` with `isnull=True` on the related name.

Python

```
users = User.objects.filter(mail_item__isnull=True)
```

How it works:

* `mail_item` is your `related_name`.

* `__isnull=True` finds users with no related mail items.

## 3. Users with more than three mail items

Use `annotate()` to count each user's mail items, then `filter()` using that count.

Python

```
from django.db.models import Count

users = User.objects.annotate(
    mail_count=Count('mail_item')
).filter(mail_count__gt=3)
```

How it works:

* `annotate()` adds a calculated count to each user.

* `Count('mail_item')` counts their mail items.

* `mail_count__gt=3` keeps users with more than 3 mail items.

### Quick recap

| ORM method      | Purpose                               |
| --------------- | ------------------------------------- |
| `filter()`      | Select records matching conditions    |
| `annotate()`    | Add a calculated value to each record |
| `Count()`       | Count related objects                 |
| `__isnull=True` | Find missing relationships            |
| `__gt=3`        | Greater than 3                        |
